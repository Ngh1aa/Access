## 1. Product Thesis

Traditional physical access control feels fragmented, hardware-heavy, slow, and disconnected from corporate IT directories. 

**ACCESS** transforms physical access into a seamless modern digital permission layer:
```
People → Identity → Credential → Building → Door → Floor → Permission
```
- **Zero-Friction for People**: Fast arrival using native Apple Wallet / Apple Watch passes, dynamic browser QR visitor links, and touchless wave-to-unlock intent.
- **Total Visibility for Security**: Centralized cloud management, sub-second SCIM directory sync (Okta, Microsoft Entra, Google Workspace, Workday), and one-click site lockdown.

- **Active Smart Readers**: Multi-spectrum LED light ring indicating `Idle/Armed` (ice-blue pulse), `Detecting` (rotating beam), `Access Granted` (emerald sweep + relay unlock), `Access Denied` (double crimson flash), and `Site Lockdown` (synchronized red strobe).

## 4. Design System & Tech Stack

- **Aesthetic Direction**: Secure · Architectural · Frictionless
- **Color Palette**: Graphite / Near-Black (`#090B0E`), Crisp Architectural Canvas (`#F8F9FA`), Cobalt Blue (`#2563EB`), Ice Blue (`#38BDF8`), Emerald Signal (`#10B981`), Warning Amber (`#F59E0B`), and Crimson Lockdown (`#EF4444`).
- **Typography**: Neo-grotesk display (`Plus Jakarta Sans`), neutral body (`Inter`), and technical hardware monospace (`DM Mono`).
- **Responsive Viewports**: 1440px+ (Desktop Primary), 1024px (Tablet Landscape), 768px (Tablet Portrait), and 390px (Mobile Portrait) with zero horizontal overflow.
- **Accessibility**: Targeted WCAG 2.2 AA compliance with non-color-reliant status cues (icon + label + color) and `@media (prefers-reduced-motion: reduce)`.
