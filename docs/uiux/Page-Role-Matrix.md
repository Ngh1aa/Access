# ACCESS — Page Role Matrix & Information Architecture

## 1. Information Architecture (IA)

```
ACCESS Platform
│
├── Home (index.html)
│   ├── Cinematic Hero & Smart Reader Demonstration
│   ├── Visual Signature: Credential Crossing Physical Space
│   ├── 01 — One credential. Every workplace (Mobile/NFC/QR/Badge)
│   ├── 02 — From invitation to entry (Visitor Journey Flow)
│   ├── 03 — Security follows identity (IdP Sync Diagram)
│   ├── 04 — Access adapts to every space (Architectural Spatial Matrix)
│   ├── 05 — Built for moments that matter (Scenario Switcher)
│   ├── 06 — One platform across every site (Global Architecture)
│   ├── Interactive Reader Sandbox
│   └── Enterprise Trust, Standards & Conversion CTA
│
├── Products
│   ├── Access Control (access-control.html)
│   │   └── Smart readers, triple unlock, door schedules, remote unlocks, lockdown
│   ├── Mobile Access (mobile-access.html)
│   │   └── Apple Wallet pass, Apple Watch, intent unlock, lost device revocation
│   ├── Visitor Management (visitor-management.html)
│   │   └── Pre-registration, touchless kiosk, dynamic QR, host alerts, auto-expiry
│   └── Enterprise Security (enterprise.html)
│       └── Multi-site control, SCIM sync, role-based zoning, compliance audit logs
│
├── Solutions & Integrations
│   └── Integrations (integrations.html)
│       └── Identity, HR, Communications, Physical Video & Locks
│
└── Conversion
    └── Book a Demo (demo.html & Interactive Modal)
        └── Enterprise qualification form, deployment timeline calculator
```

## 2. Page Role Specifications

| Page Route | Primary Persona / Intent | Hero Experience / Visual Focus | Key Interactive Component |
| :--- | :--- | :--- | :--- |
| `index.html` | Enterprise Decision Makers, VP Workplace, CISO | Architectural entrance, Smart Reader mockup, live digital pass, high-trust typography | Live Smart Reader Sandbox (switch personas & test unlocks) |
| `access-control.html` | Physical Security Directors, Facility Managers | Hardware engineering, IP65 Mullion reader render, sub-second unlock metrics | Interactive Door State simulator (Locked, Unlocked, Lockdown) |
| `mobile-access.html` | IT Administrators, Modern Workplace Leads | Ultra-clean smartphone renders with Apple Wallet pass for Đỗ Anh Nghĩa | Tap-to-unlock & Remote unlock simulator |
| `visitor-management.html` | Front Desk Managers, People Ops, Guests | Inviting hospitality lobby, reception kiosk, visitor pass for Marcus Chen | Visitor Journey interactive timeline & dynamic QR generation |
| `enterprise.html` | Enterprise CIOs, Global Security Directors | Multi-site map (Singapore, London, New York, Tokyo, HCMC), SCIM architecture | SCIM / Okta / Entra sync animation & Lockdown control |
| `integrations.html` | Enterprise Architects, Systems Integrators | Clean integration ecosystem cards organized by technical layer | Integration selector showing data flow & automated action |
| `demo.html` | Qualified Enterprise Buyers | Clean 2-column conversion layout with trust badges and preview | Interactive Rollout Timeline estimator based on locations |
