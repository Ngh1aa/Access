# ACCESS — Project Truth & Positioning Document

## 1. Core Identity & Positioning
- **Product Name**: ACCESS
- **Tagline**: "Access without friction. Security without compromise."
- **Supporting Narrative**: "Control who enters, where they can go and for how long — across every workplace from one secure cloud platform."
- **Repositioning Pivot**: Shifted from generic admin/collaboration dashboard to **Cloud Physical Access & Visitor Security Platform for Modern Workplaces**.
- **Portfolio Category**: B2B SaaS & Enterprise — Physical Security / Enterprise Access.
- **Visual Stance**: Secure · Architectural · Frictionless.
  - Distinct from Capital Place (commercial real estate / luxury brass & dark bronze).
  - Distinct from CENNEXT (corporate B2B brand platform).
  - Distinct from Sentry (monitoring SOC console).

## 2. Core Mental Model & Conceptual Loop
Physical access functions as modern digital permission:
```
People → Identity → Credential → Building → Door → Floor → Permission
```
- **Employee**: Zero-friction arrival with Apple Wallet / watch tap or wave intent.
- **Visitor**: Frictionless invitation link → instant verification & NDA → temporary dynamic QR / browser pass → tap to enter → automatic host ping → automatic expiration.
- **Contractor**: Explicit time-bounded, zone-restricted physical credential with automated revocation.
- **Security / IT Admin**: Centralized cloud governance, instant SCIM sync (Okta, Entra, Workday), real-time floor audit logs, and one-click emergency lockdown.

## 3. Anti-Dashboard Mandate
- Ratio: **75% product storytelling, spatial UX, physical-digital hardware interaction** vs. **25% administrative UI**.
- No generic 4-card KPI blocks as hero.
- No endless data tables as primary product presentation.
- Real architectural photography, high-fidelity device renders, and interactive smart hardware reader simulation.

## 4. Technical Constraints
- Repository: `https://github.com/Ngh1aa/Access`
- Live Target: `https://ngh1aa.github.io/Access/`
- Tech Stack: Pure HTML5, Modern Vanilla CSS, Vanilla JavaScript (zero heavy framework dependencies for instant load and GitHub Pages compatibility).
- Target Viewports: 1440px (Desktop primary), 1024px (Tablet landscape), 768px (Tablet portrait), 390px (Mobile portrait).
- Accessibility: WCAG 2.2 AA target with status redundancy (icon + text + color) and `prefers-reduced-motion` compliance.
