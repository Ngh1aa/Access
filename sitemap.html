03.03

Role-to-route matrix

Each screen answers a different enterprise question.

CISO

Can I govern access globally?

Enterprise Security → sites, zoning, auditability, lockdown.

SECURITY

Can I trust the door state?

Access Control → reader health, schedules, remote unlock, denied states.

IT ADMIN

Can identity drive access automatically?

Mobile + Integrations → SCIM, credential lifecycle, lost-device revocation.

PEOPLE OPS

Can visitors enter safely without friction?

Visitor Management → invitation, verification, host handoff, expiry.

BUYER

Will this fit our footprint?

Demo → site complexity, rollout constraints and deployment path.
