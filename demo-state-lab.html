Evidence boundary: network failure is deliberately simulated client-side. This proves validation/loading/error/retry/success interaction states exist; it does not prove a production booking backend, SLA, security certification or business conversion outcome.

State contract

01 · VALIDATIONCorrect before submit

Required fields expose an error next to the affected control and move focus to the first invalid field.

02 · LOADINGBlock duplicate action

Submit is disabled while the request is being processed.

03 · ERRORPreserve context

Entered values stay intact; the user can retry instead of reconstructing the request.

04 · RECOVERYExplicit retry

Retry is a deliberate action and does not hide the prior failure.

05 · SUCCESSClear completion

Only after retry succeeds does the prototype show a completed state.
